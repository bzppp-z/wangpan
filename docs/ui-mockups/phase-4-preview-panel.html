尺寸与交互
· 第三个 splitter 子控件，默认 360，最小 280；关闭后 setVisible(false)，列表占满。
· 标题高 40：文件名 12px #1F2329 超长中间省略；右侧 24×24 关闭按钮；下方灰色 12px 显示大小与类型。
· 图片：适应面板；滚轮以鼠标为中心缩放 10%–500%；双击图片恢复适应；比例显示在标题右侧。
· 文本：QPlainTextEdit 只读、Consolas 12px、NoWrap、背景 #FFFFFF。
六种状态与切换
· QStackedWidget：空 / 加载 / 文本 / 图片 / 不支持 / 错误，只切页不重建控件。
· 预览请求失败 415 → 不支持页（含"下载"按钮）；404 → 错误页"文件已被删除"并自动刷新列表。
· 图片解码失败也归入不支持页，避免显示半张图。
· 截断提示条只出现在文本页且服务端带 X-Truncated: 1。
1024×640（最小窗口）
树 200 · 列表 ≥ 320 · 预览 300，三栏无遮挡；状态栏两侧摘要同时出现时配额文案中间省略。
1366×768（常用窗口）
树 240 · 列表自适应 · 预览 360；预览打开后仍能完整显示"名称 / 大小 / 修改时间"三列。
